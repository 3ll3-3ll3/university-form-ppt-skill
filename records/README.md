# 生成记录归档

本目录保存该 Skill 每次成功生成的记录。

目录结构：

```text
records/
  <中文学校名>/
    <record>.md
    <record>.pptx
    <record>.png
```

规则：

- 子文件夹必须使用中文学校名。
- 同一次生成的 MD、PPTX、PNG 使用相同文件名 stem，优先使用本次生成的 student ID。
- PNG 必须由对应 PPT 直接渲染得到，不能使用 AI 生图替代。
- MD 记录中应写明学校、校区、表单字段、经纬度、随机姓名、学号等，并在文件尾部使用相对路径链接对应 PPT 与 PNG。
- 同一所学校的多次生成继续放在同一学校文件夹内。
