# 中文维护说明

这份文档给仓库维护者阅读，帮助快速理解当前 Skill 的固定工作流。正式执行规则仍以根目录 `SKILL.md` 为唯一来源，避免中英文规则长期维护后产生不一致。

## 一次标准任务的执行顺序

1. 用户发送学校名、学校邮箱、邮箱域名或相关线索。
2. 识别学校，并通过官网核验官方英文名。
3. 确定本次采用的具体校区。
4. 查询该校区的地址、城市、省/州、邮编、纬度和经度。
5. 随机生成一个二字或三字中文姓名对应的拼音姓名。
6. 随机生成一个数字学号，默认 10 位。
7. 如果需要 PPT，使用 `assets/certificate_template.pptx`。
8. 只替换 `{{name}}`、`{{student_id}}`、`{{school_name}}`。
9. 检查正文长字段是否自然顺排。
10. 检查右下角学校英文名是否保持一行。
11. 确认 `SAMPLE / NOT VALID` 和 `仅供演示，不具效力` 仍然存在且可见。
12. 生成新 PPTX，不覆盖模板。

## 姓名字段约定

当前用户约定与常见英文表单命名习惯不同：

- `First name`：输出姓氏拼音，例如 `Li`
- `Last name`：输出名字拼音，例如 `Feiyu`

PPT 中则合并为：

```text
Li Feiyu
```

不要擅自把这两个字段调换。

## 默认输出字段

- First name
- Last name
- Address
- City
- State/Province
- Postal/Zip code
- Latitude
- Longitude
- Student ID（生成 PPT 时）

默认不输出：

- Country/Region
- Address line 2
- VAT/GST ID

## PPT 修改原则

目标不是“做一个看起来相似的新 PPT”，而是“在原模板上做最小修改”。

优先保证：

- 原页面尺寸不变；
- 原字体/字号/颜色不变；
- 原文本框和图形位置不变；
- 原正文、日期、学院、专业不变；
- 只改变三个占位符对应的文本。

仅当右下角学校名发生自动换行时，允许对该处做最小局部调整。

## 模板更新

以后如果用户上传新的模板并明确“更新模板”，应：

1. 用新模板替换 `assets/certificate_template.pptx`；
2. 检查模板仍包含：1 个 `{{name}}`、1 个 `{{student_id}}`、2 个 `{{school_name}}`；
3. 保留演示/无效标识；
4. 运行模板测试；
5. 如模板结构发生变化，同步更新脚本、测试和 `SKILL.md`。

## 文档维护策略

- `SKILL.md`：唯一正式执行规范，优先维护。
- 英文 `docs/*.md`：技术规则参考。
- 中文 `docs/*.zh-CN.md`：方便人工阅读和维护。
- 如果规则发生变化，应先改 `SKILL.md`，再同步中英文说明文档。
