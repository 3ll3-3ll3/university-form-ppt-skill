# School research policy

## Institution identification

For an email/domain, verify the domain against the university's official website or authoritative institutional pages. Do not assume that a brand-like `.com` domain is an official university email domain.

## Campus choice

Use the campus that corresponds to the official current contact/admissions address when the user's input does not specify a campus. If multiple campuses remain equally plausible, state which campus was selected.

## English name

Use the university's own official English name, not a machine-translated alternative.

## Coordinates

Coordinates must correspond to the same campus/address used in the form fields.

Preferred order:

1. official university campus/map page with coordinates;
2. reputable map/geocoding source for the verified official address;
3. secondary geographic database with cross-checking.

Prefer WGS84 for output. China map services may expose GCJ-02 or BD-09; normalize before returning when possible.
