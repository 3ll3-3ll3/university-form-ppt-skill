# PPT 替换规则

## 只允许替换的占位符

- `{{name}}`
- `{{student_id}}`
- `{{school_name}}`

当前模板约定：

- `{{name}}` 1 处；
- `{{student_id}}` 1 处；
- `{{school_name}}` 2 处：正文一次、右下角落款一次。

正文和右下角两个学校名必须使用完全相同的学校官方英文全名。

## 实现原则

优先直接修改 PPTX 内部 slide XML 中的占位符文本，不重建整页或整个文本框，以最大限度保护模板格式。

## 严格保护的内容

除右下角学校名区域允许的最小局部适配外，禁止修改：

- 页面尺寸；
- 背景/图片；
- 主题；
- 图形；
- 正文字体；
- 正文字号；
- 正文字色；
- 正文行距；
- 正文段距；
- 正文文本框大小；
- 正文文本框位置；
- 日期；
- 学院/系/School 名称；
- 专业/项目文本；
- 其他所有非占位符正文；
- 整体版式。

## 第一行适配

包含随机姓名和 Student ID 的第一行必须完整保持单行。

- 每次生成新的纯数字 Student ID；
- 通常优先 7–8 位；
- 除非用户明确要求，不默认添加固定前缀；
- 如果第一行换行，先重新生成更短姓名；
- 仍换行再重新生成更短 Student ID；
- 每次调整后都要重新渲染检查；
- 禁止为了塞入第一行而修改正文字体、字号、行距、正文文本框或正文位置；
- 禁止交付 `student ID:` 或学号数值单独掉到下一行的版本。

## 第二行及之后的正文

正文必须像正常连续英文段落一样自然顺排。

- 替换内容继续作为原句的一部分；
- 学校英文全名较长时允许自然换行；
- 禁止在占位符前后人为插入硬换行；
- 禁止人为硬拆单词；
- 禁止故意让字段或相邻单词独占一行。

## 右下角学校落款

右下角必须使用学校官方英文全名，并始终保持一行。

优先保持原格式。若官方全名确实放不下，只允许对右下角学校名这一处做最小必要适配：

- 极小幅增加文本框宽度；
- 极小幅调整位置；
- 极小幅调整字间距；
- 必要时极小幅缩小该处字号。

不得因此修改正文或整体版式，也不得改成简称/缩写。

## 演示/无效标识

如果当前源模板含以下任一标识：

- `SAMPLE / NOT VALID`；
- `仅供演示，不具效力`；

则必须永久保留并保持可见，禁止删除、遮挡、裁剪、隐藏或弱化到不可见。

该规则以“源模板中存在”为前提；新模板若本身不含某个标识，不应假定它必然存在。

## 交付前必须渲染检查

每次生成后必须把实际 PPT 渲染为 PNG 并肉眼检查，AI 生图不能代替 PPT 预览。

检查所有适用项：

1. 姓名 + Student ID 完整留在第一行；
2. Student ID 没有单独掉行；
3. 后续正文自然顺排；
4. 正文学校名为核实后的官方英文全名；
5. 右下角学校名与正文使用同一个官方英文全名；
6. 右下角学校名保持一行；
7. 非占位符可见内容没有误改；
8. 整体格式/版式正常；
9. 若源模板含 `SAMPLE / NOT VALID`，则仍保持可见；
10. 若源模板含 `仅供演示，不具效力`，则仍保持可见。

任何适用项失败，都必须重新生成/修正并再次渲染后再交付。

## 输出文件

始终生成新的 `.pptx`，不得覆盖用户上传的源模板。
